## Frameworks & Libraries

| Name | Language | Description |
|------|----------|-------------|
| [LangChain](https://github.com/langchain-ai/langchain) | Python/JS | Framework for building LLM-powered applications |
| [LangGraph](https://github.com/langchain-ai/langgraph) | Python | Build stateful, multi-actor agents with graphs |
| [CrewAI](https://github.com/crewAIInc/crewAI) | Python | Framework for orchestrating AI agent crews |
| [AutoGen](https://github.com/microsoft/autogen) | Python | Microsoft's multi-agent conversation framework |
| [Claude Agent SDK](https://github.com/anthropics/claude-code) | Python/TS | Anthropic's SDK for building Claude-powered agents |
| [Semantic Kernel](https://github.com/microsoft/semantic-kernel) | C#/Python | Microsoft's AI orchestration SDK |
| [Haystack](https://github.com/deepset-ai/haystack) | Python | End-to-end NLP framework for building AI pipelines |
| [Instructor](https://github.com/instructor-ai/instructor) | Python | Structured outputs from LLMs |
